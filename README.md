# 通讯录

本仓库中的 V3 是 Python/Tkinter 桌面版，支持联系人增改删、多条联系方式、收藏筛选和 Excel 导入导出。

[在线演示（网页版）](http://117.50.199.166/addressbook/) 是单独部署的实现，可直接在浏览器运行。桌面版使用本地 JSON 文件，网页版使用当前浏览器的存储。如需在两者间迁移，可以通过 Excel 导出后再导入。

## 运行桌面版

使用带 Tkinter 的 Python 3.12。在项目目录安装依赖后启动应用：

```powershell
python -m pip install -r requirements.txt
python app.py
```

如果项目目录已经准备了 `.venv`，可以在 Windows PowerShell 直接使用该环境启动：

```powershell
.\.venv\Scripts\python.exe app.py
```

选择「新增联系人」并填写姓名。电话、邮箱、社交账号和地址均可分别填写多项，每行一项。点击列表中的联系人查看详情，或使用「编辑」「删除」修改记录。

选中联系人后点击「收藏」，列表会显示星标。「只看收藏」用于切换到收藏列表，再次点击「取消收藏」即可移除星标。

通讯录保存在项目内的 `data/contacts.json`，此目录由 Git 忽略。

## Excel 导入导出

- 「导出 Excel」始终导出全部联系人，可以导出空通讯录作为模板。
- 导入读取第一个工作表。第一行依次填写 `姓名`、`电话`、`邮箱`、`社交账号`、`地址`、`收藏`。每人一行，同一类有多项时在单元格内换行。保留前导零的号码请用文本格式填写。收藏列使用「是」「否」或留空。
- 导入会追加联系人。同一文件再次导入会再次添加。任意一行出现格式错误时，应用显示原因，本次导入的数据不会写入。

## 快速验收

1. 添加一位联系人，在电话栏填写两个号码（其中一个以 `0` 开头），保存后将其收藏。关闭并重开应用，确认详情和星标仍在。
2. 导出表格并在 Excel 中对照第一行列名和联系人数据。用表格导入，确认新增的联系人保留多项联系方式和收藏状态。
3. 用错误列名另存一份表格并尝试导入。确认看到错误提示，联系人数量保持原样。
